# Karobar E-Commerce Platform

A full-featured clothing e-commerce website with MERN stack.

## Features
- User authentication with OTP verification
- Product browsing, search, filters
- Shopping cart and Razorpay payment integration
- Seller dashboard for product/order management
- Admin panel for complete control
- AI chatbot for product recommendations
- Real-time notifications and live chat
- Invoice generation and order tracking

## Tech Stack
- Frontend: React, Redux Toolkit, Tailwind CSS
- Backend: Node.js, Express, MongoDB
- Payments: Razorpay
- AI: OpenAI GPT-3.5
- Real-time: Socket.io

## Installation
1. Clone the repo
2. Install dependencies: `cd client && npm install`, `cd server && npm install`
3. Set up environment variables (see .env files)
4. Run MongoDB
5. Start server: `npm run dev` in server folder
6. Start client: `npm run dev` in client folder

## Environment Variables
See `.env.example` files in both client and server directories.
